# ReadRay 首版发布清单

## 发布定位

- 版本：`v0.1.0 Preview`
- 平台：Windows x64
- 分发格式：NSIS 安装包（`ReadRay_0.1.0_x64-setup.exe`）
- 安装模式：当前用户安装，不要求管理员权限；安装器提供安装目录选择、开始菜单快捷方式和 MIT 许可页。
- 阶段边界：阶段一至阶段八点五已收口；阶段九的学习者画像、长期记忆、个性化排序和效果评估不属于本版本承诺。

首版目标是获得真实用户反馈，因此发布说明应使用 Preview，而不是暗示所有长期学习能力已经完成。

## 本地构建

在仓库根目录执行：

```powershell
& 'D:\Application\nvm\nodejs\pnpm.cmd' release:build
```

产物目录：

```text
src-tauri\target\release\bundle\nsis\
```

校验安装包：

```powershell
Get-FileHash -LiteralPath 'src-tauri\target\release\bundle\nsis\ReadRay_0.1.0_x64-setup.exe' -Algorithm SHA256
```

每次上传 GitHub Release 时，应把 SHA-256 写入发布说明，方便用户确认下载完整性。

## 发布前人工验收

在尽量干净的 Windows x64 环境中，由发布者完成一次真实安装测试：

1. 双击安装包，确认可以选择安装目录、安装过程不要求管理员权限，开始菜单快捷方式可用。
2. 首次打开后确认未配置 API Key 时显示引导卡片；点击“配置 API Key”应直达“设置 → AI 服务”，填写并验证 DeepSeek API Key；确认密钥不会出现在 SQLite、普通日志或导出的数据中。
3. 在新安装中验证双击左 Alt 划词解释、`Alt+Win+Space` Quick AI、主窗口、托盘、对话、写作、今天、记忆和复习等首版核心链路；再用已有用户数据升级，确认旧默认值或用户自定义快捷键保持不变。
4. 退出并重新打开应用，确认本地数据、主题、窗口状态和未完成对话的恢复行为符合预期。
5. 卸载后确认卸载器正常工作，并按发布说明明确本地学习数据是否保留；不要把用户数据清理行为留给用户猜测。
6. 在另一台未预热环境复测 WebView2 安装路径。当前安装包嵌入 WebView2 bootstrapper；若机器无法联网，需在发布说明中明确离线安装限制。

## 发布者需要亲自完成的事项

- 代码签名证书的购买、保管和签名。当前构建没有伪造签名；未签名安装包可能触发 Windows SmartScreen 提示，签名后再上传最终文件。
- 审阅本次代码和配置差异，提交版本变更，创建并推送 `v0.1.0` tag。
- 在 GitHub 创建 `v0.1.0` Release，标题标明 `Preview`，上传签名后的 NSIS 安装包和 SHA-256，附上已知限制、API Key 配置方式和卸载/数据保留说明。
- 用发布页面上的最终下载链接做一次“下载 → 安装 → 首次配置”复测，再把链接提供给用户。

## 暂不启用

首版不半接入自动更新。Updater 需要额外的签名密钥、更新端点和升级回滚验证；等 Preview 收集到反馈并稳定发布流程后，再单独设计更新协议。
